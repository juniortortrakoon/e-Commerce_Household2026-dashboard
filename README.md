## วิธีรันครั้งแรก
```
npm install
npm run dev
```

## Deploy (Vercel/Netlify)
Build command: `npm run build`
Output directory: `dist`

หมายเหตุ: ตั้งชื่อโปรเจกต์บน Vercel ต้องเป็นตัวพิมพ์เล็กทั้งหมด (a-z, 0-9, '.', '_', '-')
